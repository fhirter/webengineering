# Übung Accessibility

## Lernziele

Die Studierenden können barrierefreie Webseiten erstellen.

## Aufgabenstellung

Führe für eine Website oder Web-Applikation deiner Wahl eine Accessibility-Überprüfung durch. Wähle eine eigene Website
oder eine eher einfache Website (https://teko.ch, https://fabianhirter.ch, https://hirschengraben.net).

Nutze das [WCAG-EM Report Tool]( https://www.w3.org/WAI/eval/report-tool) oder
die [Checkliste von https://a11y.digitaldialog.swiss/](https://a11y.digitaldialog.swiss/checklist). Beide basieren auf
den Erfolgskriterien der [Web Content Accessibility Guidelines 2.2](https://www.w3.org/TR/WCAG22/). Im WCAG Tool können
Schritte 2 und 3 übersprungen werden. Bearbeite die Erfolgskriterien nicht streng von oben nach unten, sondern wähle
gezielt Punkte aus, sodass du am Ende zu allen Prinzipien und Richtlinien mindestens ein Erfolgskriterium überprüft
hast. 
Wähle den Level A, um dich auf die wichtigsten Regeln zu beschränken.

In den [Tutorials](https://www.w3.org/WAI/tutorials) findest du weitere Informationen.

Nutze sowohl automatische als auch manuelle Tests.

## Ergebnisse

Halte die Erkenntnisse in einem Dokument fest und formuliere eine Empfehlung, wie die Barrierefreiheit verbessert werden
kann.

Präsentiere am Ende der Unterrichtseinheit die Ergebnisse der Klasse mit einer Flipchart.
