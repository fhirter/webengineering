# Übung Accessibility

## Lernziele

Die Studierenden können barrierefreie Webseiten erstellen.

## Aufgabenstellung

Führe für eine Website oder Web-Applikation deiner Wahl eine Accessibility-Überprüfung durch. Wähle eine eigene Website
oder eine eher einfache Website (https://teko.ch, https://fabianhirter.ch, https://hirschengraben.net).

Nutze die Erfolgskriterien der [Web Content Accessibility Guidelines 2.2](https://www.w3.org/TR/WCAG22/). Bearbeite die
Erfolgskriterien nicht streng von oben nach unten, sondern wähle gezielt Punkte aus, sodass du am Ende zu allen
Prinzipien und Richtlinien mindestens ein Erfolgskriterium überprüft hast.

Nutze sowohl automatische als auch manuelle Tests.

## Ergebnisse

Halte die Erkenntnisse in einer tabellarischen Übersicht fest, schreibe eine kurze Bewertung, welchem Level (A, AA,
AAA) die Website entspricht und formuliere eine Empfehlung, wie die Barrierefreiheit verbessert werden kann.
Nutze die das [WCAG-EM Report Tool]( https://www.w3.org/WAI/eval/report-tool).

Präsentiere am Ende der Unterrichtseinheit die Ergebnisse der Klasse.
