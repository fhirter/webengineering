# Übung Testing

## Lernziele

Die Studierenden können Anwendungen mit automatisierten Akzeptanz- und Unit-Tests testen.

## Akzeptanztests

Mache dich mit [Playwright vertraut](https://playwright.dev/docs/intro):

- Initialisiere die Beispielapplikation mit `npm init playwright@latest` und starte die Beispieltests.
- Schau dir mit `npx playwright show-report` die HTML Reports an.
- Lasse die Tests mit UI laufen: `npx playwright test --ui`.

Wenn du mit Playwright vertraut bist, kopiere die [Vorlage der bewerteten Übung](../../Assignments/02_WebApplications)
und lasse den Test laufen.

Starte anschliessend mit der Implementierung der Arbeit.
