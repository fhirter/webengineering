# Übung Webserver

Installiere mit Docker den Apache-Webserver lokal oder auf einem Raspberry-PI und veröffentliche folgende HTML-Datei:

```html
<!DOCTYPE html>
<html lang="de">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Titel</title>
  </head>
  <body>
    Test erfolgreich!
  </body>
</html>
```
