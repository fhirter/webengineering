# Übung Performance

Untersuche eine Applikation auf Performance-Optimierungsmöglichkeiten und setze diese um.

## Lernziele

Die Studierenden kennen Werkzeuge zur Performance-Analyse und können diese einsetzen und Performance-Probleme beheben.

## Vorgehen

Untersuche eine von dir entwickelte Applikation oder eine beliebige andere Browserapplikation oder Website.
Charakterisiere die Performance der Applikation in einem Dokument anhand von klar messbaren Metriken, beispielsweise
Ladezeiten (https://developer.mozilla.org/en-US/docs/Web/Performance/Guides/How_long_is_too_long) oder das Verhalten
nach dem Laden.

Identifiziere Punkte, die verbessert werden können, und schreibe einen automatischen Performance-Test für jeden Punkt.

Untersuche, wie dies verbessert werden könnte.

Implementiere die Änderung, falls es sich um eine eigene Applikation handelt. Überprüfe am Anschluss die Änderungen.

Wenn es sich um eine fremde Applikation oder Website handelt, schätze, welchen monetären Einfluss eine
Performance-Verbesserung auf das Unternehmen haben könnte (https://research.google/blog/speed-matters/).

Präsentiere die Untersuchungen in einer kurzen Präsentation der Klasse.

Arbeite nach wissenschaftlichem Vorgehen!
