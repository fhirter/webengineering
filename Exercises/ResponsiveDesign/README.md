# Responsive Design

## Lernziele

Die Studierenden

- kennen die Anwendungsbereiche von Flexbox und Grid
- kennen die Layoutkonzepte mobile first und device agnostic.
- können Layouts entwickeln, die auf einer Vielzahl von unterschiedlichen Geräten einwandfrei funktionieren
- können einfache Mehrspaltenlayouts erstellen

## Aufgabenstellung

Erstelle für die Gruppenarbeit ein ansprechendes Layout, welches für möglichst viele Bildschirmgrössen funktioniert.

Orientiere dich bei der Bestimmung der Breakpoints, also den Punkte, wo das Layout ändert, am Inhalt der Website, nicht
an Gerätegrössen (device agnostic).

Erstelle zuerst das Layout für Mobilgeräte (mobile first).

Halte die wichtigsten Punkte in einer Flipchart fest (z.B. MS Whiteboard).
