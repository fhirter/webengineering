# Gruppenarbeit Web-Engineering TEL

Entwickle in Zweiergruppen eine Web-Applikation, die Daten aus einer CSV-Datei ausliest und im Browser darstellt.

## Lernziele und Kompetenzen

Die Studierenden...

- können die HTML-Grundelemente korrekt anwenden (Überschriften, Absätze, Tabellen, Listen, Links, HTML5
  Struktur-Elemente) und können damit einfache Seiten komplett erstellen.
- können einfache Stylesheets erstellen und einbinden und dabei Selektoren, Farben, Einheiten korrekt verwenden.
- können mit Flexbox und Grid einfache Mehrspaltenlayouts erstellen.
- können einfache interaktive Anwendungen mit clientseitiger Logik entwickeln.
- können Webseiten mit einem Webserver auf einem Single-Board-Computer bereitstellen.

Es sollen nur Code und Dokumente geschrieben werden, deren Funktion und Inhalt vollständig verstanden wurde. Dies wird
an der mündlichen Prüfung kontrolliert.
Siehe auch [Hinweise zur Verwendung von KI](https://github.com/fhirter/Software-Engineering/blob/master/Readings/BerichteSchreiben/VerwendungVonKIinArbeiten.md).

## Aufgabenstellung

Wir nehmen an, dass wir eine Sensoranwendung haben, die Daten periodisch in ein CSV-File schreibt. Ein Webserver stellt
diese Daten über HTTP zur Verfügung.

Zeige die Daten auf einer HTML-Seite tabellarisch an.

Formatiere die Inhalte mit CSS.

Lade die Daten periodisch mit JavaScript und aktualisiere die Tabelle.

Mögliche Weiterentwicklungen:

- Konvertiere die CSV-Daten auf dem Server in JSON-Daten
- Lade die Daten auf dem Server in eine Datenbank
- Visualisiere die Daten mit einem Diagramm
